# The Wealth Table

Static website for thewealthtableglobal.com, plus the brand kit.

## Website
- `index.html`, `gallery/nairobi/`, `gallery/accra/`: generated by `python3 scripts/build_site.py` from `scripts/content.json` (committed output; Vercel needs no build step).
- `assets/`: CSS, JS, fonts, logos, photos, flags.
- **Register buttons**: every "Register your interest" button reads `assets/js/config.js`. Set `LUMA_URL` (and optionally `LUMA_EVENT_ID` for Luma's on-page checkout). Currently: https://luma.com/3b32d6aa.
- Deploys from GitHub to Vercel (`vercel.json`, `.vercelignore`).

## Brand kit
`brand-kit/`: start with `Wealth-Table-Brand-Guidelines.pdf` and `brand-kit/README.md`. Generators are in `scripts/brand/`
(`PYTHONPATH=/tmp/pylibs python3 scripts/brand/build_logos.py`, then `build_posters.py`, `build_social.py`, `build_guidelines.py`; needs `pip install fonttools brotli potracer` and Playwright).

## Other
`docs/`: site extraction log, reference notes, concept playbook. `archive/`: earlier concept rounds (not deployed).
