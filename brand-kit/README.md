# The Wealth Table: Brand Kit (v1.0)

Open `Wealth-Table-Brand-Guidelines.pdf` first (also as `.html`).

| Folder | Contents |
|---|---|
| `logos/svg`, `logos/png` | 7 marks (primary stacked, horizontal, wordmark, monogram, seal, table mark, monogram ring) in 5 colours. SVG files are true vector (traced from the supplied logo). |
| `icons/` | 12 line icons, SVG + PNG |
| `avatars/` | 8 profile images, 1080 px (safe for circle crop) |
| `art/` | Ripple and seat backgrounds (3000×2000 PNG + SVG) and tileable patterns |

| `social/` | Instagram posts (14), stories (4), highlight covers (6), LinkedIn posts (6) and banners (2), 5-slide carousel |

## Notes
- The wordmark, WT monogram and tagline were traced from the existing logo files. If you have the original vector artwork, use it as the master and keep these as working copies.
- Posters and social graphics were generated by scripts in `scripts/brand/` (HTML to PNG/PDF), so any text can be edited and re-rendered.
- Accra and Nairobi poster photos are 1600 px originals: fine for screens and A4-size print, but ask the photographers for full-resolution files before printing large formats.
- The Lagos poster states 11:00 AM – 5:00 PM (WAT), as on the website. The old poster said 12:00 PM. Confirm before printing.
- Accra photos carry a "QJ pictures" mark that was cropped out of the web and poster versions. Confirm usage and credit with the photographer.
